## Evidence-state rule

A reference may justify architecture, but it does not prove implementation. Each row distinguishes the external basis from current code and from the test evidence still needed. Command-plan tests and backend-applied inspect state are never cited as proof that real kernel/runtime enforcement occurred. Effective security claims require positive evidence tied to the exact sandbox identity and supported backend/runtime version.
