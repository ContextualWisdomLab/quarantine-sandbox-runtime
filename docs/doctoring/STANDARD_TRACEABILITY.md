## Evidence-state rule

A reference may justify architecture, but it does not prove implementation. Each row distinguishes the external basis from current code and from the test evidence still needed. Command-plan tests are never cited as evidence that real container isolation succeeded. For hostile command execution, a positive attestation obtained only after the consumer payload was already runnable also does not prove a pre-execution isolation boundary.
